# Bai OS UI (Rust + Slint)

รัน:  cargo run --release

- Linux: ต้องมี fontconfig / libxkbcommon (ปกติมีอยู่แล้ว)
- ปัดขึ้นที่หน้าล็อก = ปลดล็อก | ปัดลงจากขอบบนที่หน้าหลัก = ศูนย์ควบคุม | แตะแถบล่าง = ล็อก

ลองบนมือถือ: Slint รองรับ Android (cargo-apk / cargo-ndk) และ iOS
https://slint.dev/docs/rust/slint/docs/
